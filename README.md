# 🧠 Implementando Redes Neurais com TensorFlow

Este repositório contém notebooks e scripts práticos desenvolvidos durante aulas e estudos sobre **Inteligência Artificial e Machine Learning**. O foco principal é a construção, treinamento e avaliação de modelos de Redes Neurais utilizando a biblioteca TensorFlow.

## 📂 Estrutura do Repositório

Os projetos foram desenvolvidos no **Google Colab** (arquivos `.ipynb`) e estão divididos nos seguintes tópicos:

*   **`Implementando_MLP_TensorFlow.ipynb` / `MLP/` / `Auditório 2 - MLP/`**:
    *   Implementações práticas de **MLP (Multi-Layer Perceptron)**.
    *   Modelagem de redes neurais artificiais *feedforward* clássicas.
    *   Testes de funções de ativação, otimizadores e cálculo de perda (loss).

*   **`SOM/`**:
    *   Implementação de **SOM (Self-Organizing Maps - Mapas Auto-Organizáveis)**.
    *   Estudo de redes neurais artificiais baseadas em aprendizado não supervisionado, focadas em redução de dimensionalidade e clusterização.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Python
*   **Bibliotecas Principais:** TensorFlow, Keras, NumPy, Pandas, Matplotlib/Seaborn (para visualização de dados).
*   **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebook
